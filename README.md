# AMUDAGRO - Сайт агропредприятия

Современный сайт-визитка для агрохолдинга AMUDAGRO, специализирующегося на выращивании премиальных фруктов (нектарины и абрикосы) в Узбекистане.

## Технологии

- **Next.js 14** - React фреймворк для продакшена
- **TypeScript** - Типизированный JavaScript
- **CSS Modules** - Стилизация компонентов
- **Мультиязычность** - Русский, Английский и Узбекский языки

## Структура проекта

```
├── app/                    # Страницы приложения (App Router)
│   ├── layout.tsx         # Главный layout с LanguageProvider
│   ├── page.tsx           # Главная страница
│   ├── about/             # Страница "О компании"
│   ├── products/           # Страница "Продукция"
│   ├── export/             # Страница "Экспорт"
│   ├── gallery/            # Страница "Галерея"
│   └── contacts/           # Страница "Контакты"
├── components/            # React компоненты
│   ├── Header.tsx        # Шапка сайта с переключателем языка
│   ├── Footer.tsx        # Подвал сайта
│   ├── Hero.tsx          # Главный баннер
│   ├── Features.tsx      # Блок преимуществ
│   ├── AboutPreview.tsx  # Превью о компании
│   └── CTA.tsx           # Призыв к действию
├── contexts/              # React контексты
│   └── LanguageContext.tsx # Контекст для мультиязычности
├── lib/                   # Утилиты и данные
│   └── translations.ts   # Переводы для всех языков
└── public/               # Статические файлы
```

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Сборка для продакшена

```bash
npm run build
npm start
```

## Особенности

- ✅ **Мультиязычность** - Русский, Английский и Узбекский языки с переключателем
- ✅ **Адаптивный дизайн** - Оптимизирован для всех устройств
- ✅ **Современный UI/UX** - Зеленая цветовая схема, соответствующая агропредприятию
- ✅ **SEO-friendly** - Оптимизированная структура для поисковых систем
- ✅ **TypeScript** - Полная типобезопасность
- ✅ **Информация о технологиях** - MAF Roda, NETAFIM, DALIVAL

## Страницы сайта

1. **Главная** - Hero-секция, преимущества, информация о MAF Roda
2. **О компании** - История, миссия, преимущества, информация о сортах
3. **Продукция** - Нектарины и Абрикосы с технической информацией
4. **Экспорт** - Информация о экспорте, MAF Roda, упаковка, география поставок
5. **Галерея** - Фотографии и видео садов, урожая и фруктов
6. **Контакты** - Контактная информация, форма обратной связи, карта

## Настройка контента

Все тексты находятся в файле `lib/translations.ts`. Для изменения контента отредактируйте соответствующие разделы для русского (`ru`) и английского (`en`) языков.

- Светло-зеленый: `#4da67a`
- Акцентный оранжевый: `#ff8c42`
